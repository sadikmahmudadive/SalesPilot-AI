1. Overview

The Follow-ups & Automations module lets you set up rules that automatically act when something happens in your store. Each rule follows a simple pattern:

When [something happens] → Then [do this action]

Examples:

  • When a draft order sits unconfirmed for 30 minutes → send the customer a WhatsApp follow-up.
  • When an order is delivered → tag the customer as a repeat buyer.
  • When stock drops below 5 units → fire a webhook to n8n or Slack.

Every execution is logged with its status (Succeeded, Skipped, or Failed) so you can always see what happened and why.

2. Accessing the Automations Page

From the dashboard sidebar, click Automations (or navigate to /automations). Every role can view automations. Creating, editing, testing and running them needs the owner, admin or agent role.

5. Creating a Custom Automation Rule

Click the New Automation Rule button in the top-right corner. A dialog opens with these fields:

1
Rule Name — Give it a short, descriptive name (max 80 characters).
2
Description — Optional note for your team (max 300 characters).
3
When (Trigger) — Choose what event starts this rule. See Triggers.
4
Then (Action) — Choose what happens when triggered. See Actions.
5
Configure — Fill in the trigger-specific and action-specific settings that appear below the dropdowns.
6
Rule Enabled — Check this to activate immediately, or uncheck to save as paused.
7
Click Create Rule.

9. Managing Rules

In the Rules tab, each rule card shows its name, status (Active/Paused), trigger, action and run stats. You can:

  • Edit (pencil icon) — Opens the form dialog with current values pre-filled.
  • Delete (trash icon) — Permanently removes the rule after confirmation.
  • Pause / Enable — Toggles the rule on or off without deleting it.
  • Test — Manually triggers the rule once (see next section).

10. Testing a Rule

Click the Test button on any rule card. This manually triggers the rule with a force: true flag, meaning it bypasses the deduplication check and runs immediately. The result (succeeded/failed/skipped) appears as a toast notification.

Testing does not disable opt-out checks. If the target customer has consent denied, the run will still be skipped.

11. Running a Sweep

Click Run Sweep Now in the header to evaluate all enabled rules at once. The sweep:

  1. Loops through every enabled rule in your workspace.
  2. Checks each rule's trigger condition against current data (e.g., stale drafts, low stock).
  3. Executes the action for every matching target, with deduplication (same target won't be processed twice).
  4. Reports a summary: how many were evaluated, succeeded, skipped or failed.
Important: Rules do not run by themselves. Time-based triggers (stale drafts, confirmed or delivered orders, inactive customers, low stock) are only checked when someone clicks Run Sweep Now. There is no scheduled sweep yet, so click it regularly or ask your developer to add one.

13. Inbound & Outbound Webhooks (n8n)

Inbound Webhook (trigger from n8n)

When you create a rule with the Inbound Webhook (n8n) trigger, the system generates a unique URL for that rule. You'll see it on the rule card — click Copy to copy it.

Configure your n8n workflow to POST to this URL with this JSON body:

{ "customerId": "cust_abc123", "orderId": "order_xyz", "phone": "+8801711234567", "variables": { "customKey": "any value" } }

If you set a webhook secret, n8n must send it in the x-n8n-secret or x-automation-secret header.

Outbound Webhook (send to n8n)

When a rule's action is Send Signed Webhook, SalesPilot POSTs a JSON payload to your destination URL whenever the trigger fires. The payload includes order, customer and product data. If you set a webhook secret, the request includes an x-salespilot-signature header with an HMAC-SHA256 signature (sha256=<hex>) so n8n can verify the request is authentic.

15. FAQ & Troubleshooting

Q: Why does a WhatsApp rule show "Skipped"?

Common reasons: (a) No WhatsApp number is connected in Integrations; (b) The customer has no valid phone number; (c) The customer has opted out (consent denied).

Q: Will the same customer get the same follow-up twice?

No. The sweep uses deduplication keys (ruleId:targetType:targetId). Once a particular order or customer has been processed by a rule, it won't be processed again in future sweeps — unless you use the Test button (which forces execution).

Q: How often does the sweep run automatically?

It does not. The sweep only runs when someone clicks "Run Sweep Now". A scheduled sweep is not set up yet; your developer would need to add one.

Q: Can I use automations without WhatsApp?

Yes. The "Update Customer CRM" and "Send Signed Webhook" actions work without WhatsApp. Voice calls require the voice integration to be set up.

Q: What happens if an outbound webhook fails?

The run is recorded as Failed with the HTTP status code in the summary. Check your n8n/destination URL and retry via the Test button.

যখন [কিছু ঘটবে] → তখন [এই কাজটি করো]

উদাহরণ:

  • যখন একটি ড্রাফট অর্ডার ৩০ মিনিট ধরে অনিশ্চিত থাকে → কাস্টমারকে WhatsApp এ ফলো-আপ পাঠাও।

প্রতিটি এক্সিকিউশন লগ হয়ে থাকে — সফল, স্কিপ, অথবা ব্যর্থ — যাতে আপনি সবসময় দেখতে পারেন কি হয়েছে এবং কেন।

১

৯. রুল ম্যানেজমেন্ট

Rules ট্যাবে প্রতিটি রুল কার্ডে নাম, স্ট্যাটাস (Active/Paused), ট্রিগার, অ্যাকশন এবং রান পরিসংখ্যান দেখায়। আপনি যা করতে পারেন:

  • Edit (পেন্সিল আইকন) — বর্তমান মান দিয়ে ফর্ম ডায়ালগ খোলে।
  • Delete (ট্র্যাশ আইকন) — নিশ্চিত করার পর রুলটি স্থায়ীভাবে মুছে ফেলে।
  • Pause / Enable — রুলটি না মুছে অন বা অফ করে।
  • Test — রুলটি ম্যানুয়ালি একবার ট্রিগার করে (পরবর্তী অংশ দেখুন)।

১০. রুল টেস্ট করা

যেকোনো রুল কার্ডে Test বাটনে ক্লিক করুন। এটি force: true ফ্ল্যাগ দিয়ে রুলটি ম্যানুয়ালি ট্রিগার করে, অর্থাৎ ডিডুপ্লিকেশন চেক এড়িয়ে সাথে সাথে চলে। ফলাফল (succeeded/failed/skipped) একটি টোস্ট নোটিফিকেশন হিসেবে দেখায়।

টেস্ট করলেও অপ্ট-আউট চেক বন্ধ হয় না। যদি টার্গেট কাস্টমার consent denied করে থাকে, রান তখনও স্কিপ হবে।

১১. সুইপ চালানো

হেডারে Run Sweep Now ক্লিক করুন সকল সক্রিয় রুল একসাথে মূল্যায়ন করতে। সুইপ যা করে:

  1. আপনার ওয়ার্কস্পেসের প্রতিটি সক্রিয় রুল লুপ করে।
  2. বর্তমান ডেটার (যেমন, স্টেল ড্রাফট, কম স্টক) বিপরীতে প্রতিটি রুলের ট্রিগার কন্ডিশন চেক করে।
  3. প্রতিটি ম্যাচিং টার্গেটের জন্য অ্যাকশন চালায়, ডিডুপ্লিকেশন সহ (একই টার্গেট দুইবার প্রসেস হবে না)।
  4. সারাংশ দেখায়: কতগুলো মূল্যায়ন হয়েছে, সফল, স্কিপ বা ব্যর্থ।
গুরুত্বপূর্ণ: রুল নিজে নিজে চলে না। সময়-ভিত্তিক ট্রিগারগুলো (স্টেল ড্রাফট, কনফার্ম বা ডেলিভার্ড অর্ডার, নিষ্ক্রিয় কাস্টমার, কম স্টক) শুধু তখনই চেক হয় যখন কেউ Run Sweep Now ক্লিক করে। এখনও কোনো নির্ধারিত (scheduled) সুইপ নেই, তাই নিয়মিত ক্লিক করুন অথবা আপনার ডেভেলপারকে এটি যোগ করতে বলুন।

১৩. ইনবাউন্ড ও আউটবাউন্ড ওয়েবহুক (n8n)

ইনবাউন্ড ওয়েবহুক (n8n থেকে ট্রিগার)

Inbound Webhook (n8n) ট্রিগার দিয়ে রুল তৈরি করলে, সিস্টেম সেই রুলের জন্য একটি ইউনিক URL তৈরি করে। রুল কার্ডে এটি দেখাবে — Copy ক্লিক করে কপি করুন।

আপনার n8n workflow কনফিগার করুন এই URL এ POST করতে, এই JSON বডি সহ:

{ "customerId": "cust_abc123", "orderId": "order_xyz", "phone": "+8801711234567", "variables": { "customKey": "যেকোনো মান" } }

আপনি যদি webhook secret সেট করেন, n8n-কে x-n8n-secret বা x-automation-secret হেডারে সেটা পাঠাতে হবে।

আউটবাউন্ড ওয়েবহুক (n8n-এ পাঠানো)

রুলের অ্যাকশন Send Signed Webhook হলে, SalesPilot ট্রিগার ফায়ার হওয়ার সময় আপনার গন্তব্য URL-এ JSON পেলোড POST করে। পেলোডে অর্ডার, কাস্টমার এবং প্রোডাক্ট ডেটা থাকে। আপনি webhook secret সেট করলে, রিকোয়েস্টে x-salespilot-signature হেডার থাকে HMAC-SHA256 সিগনেচার সহ (sha256=<hex>) যাতে n8n যাচাই করতে পারে রিকোয়েস্টটি আসল কিনা।

১৫. সচরাচর জিজ্ঞাসা ও সমস্যা সমাধান

প্র: কেন একটি WhatsApp রুল "Skipped" দেখাচ্ছে?

সাধারণ কারণ: (ক) Integrations এ কোনো WhatsApp নম্বর কানেক্ট করা হয়নি; (খ) কাস্টমারের কোনো বৈধ ফোন নম্বর নেই; (গ) কাস্টমার অপ্ট-আউট করেছে (consent denied)।

প্র: একই কাস্টমার কি একই ফলো-আপ দুইবার পাবে?

না। সুইপ ডিডুপ্লিকেশন কী (ruleId:targetType:targetId) ব্যবহার করে। একটি নির্দিষ্ট অর্ডার বা কাস্টমার একবার একটি রুল দ্বারা প্রসেস হলে, ভবিষ্যতে সুইপে আবার প্রসেস হবে না — যতক্ষণ না আপনি Test বাটন ব্যবহার করেন (যা জোরপূর্বক এক্সিকিউশন করে)।

প্র: সুইপ স্বয়ংক্রিয়ভাবে কত ঘন ঘন চলে?

চলে না। সুইপ শুধু তখনই চলে যখন কেউ "Run Sweep Now" ক্লিক করে। নির্ধারিত (scheduled) সুইপ এখনও সেট করা নেই; এটি আপনার ডেভেলপারকে যোগ করতে হবে।

প্র: WhatsApp ছাড়া কি অটোমেশন ব্যবহার করা যায়?

হ্যাঁ। "Update Customer CRM" এবং "Send Signed Webhook" অ্যাকশনগুলো WhatsApp ছাড়াই কাজ করে। ভয়েস কলের জন্য ভয়েস ইন্টিগ্রেশন সেটআপ থাকতে হবে।

প্র: আউটবাউন্ড ওয়েবহুক ব্যর্থ হলে কি হয়?

রানটি Failed হিসেবে রেকর্ড হয়, সারাংশে HTTP স্ট্যাটাস কোড সহ। আপনার n8n/গন্তব্য URL চেক করুন এবং Test বাটনের মাধ্যমে পুনরায় চেষ্টা করুন।
